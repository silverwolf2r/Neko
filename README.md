# Neko
### Cat Cursor Follower

This is a remake of the Neko Cursor Follower from waaaaay back when. I remade this in Python so that it could access multiple screens as well as did some color changes for the kitty cats as I wanted to experiment with more options.
This was also my first time using ChatGPT as a hardcore helper on a program and it was an interesting experiment!
I built this to run on Windows and have not tested it on other OS's please let me know if you would like a version for other OSs.

### File Explanation
4 Exes with different color cats and the Python script.
